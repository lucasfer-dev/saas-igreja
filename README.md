# Comunidade — SaaS para igrejas

MVP de uma plataforma focada em **gestão + relacionamento + experiência do membro**.

## Visão do produto

A proposta não é competir apenas como ERP administrativo. O produto une:

- painel de liderança;
- gestão de membros e visitantes;
- jornada de acolhimento e follow-up;
- eventos e comunicação;
- portal responsivo para membros;
- notícias, rádio e convites;
- base preparada para personalização por igreja.

## Rotas

- `/` — apresentação do produto
- `/admin` — dashboard administrativo demonstrativo
- `/membros` — experiência do membro

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
